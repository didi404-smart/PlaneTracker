# PlaneTracker

Консольная программа, которая собирает данные о самолётах, находящихся в воздушном пространстве выбранной страны, и сохраняет их в JSON-файл.

Источники данных:

- [nominatim.openstreetmap.org](https://nominatim.openstreetmap.org/) — географические границы страны;
- [opensky-network.org](https://opensky-network.org/) — самолёты внутри этих границ.

## Возможности

- запрос самолётов по названию страны;
- автоматическое сохранение результата в `data/aeroplanes.json` (повторный запрос обновляет уже известные самолёты, а не дублирует их);
- топ N самолётов по высоте полёта;
- фильтрация самолётов по стране регистрации.

## Установка

Требуется Python 3.10 или новее.

```bash
poetry install
```

## Запуск

Из корня проекта:

```bash
python main.py
```

Меню программы:

```
1. Запросить самолёты над страной
2. Топ N самолётов по высоте
3. Самолёты по стране регистрации
0. Выход
```

Пункты 2 и 3 работают с результатом последнего запроса (пункт 1), поэтому сначала нужно запросить самолёты.

Страну можно вводить на английском (например, `Spain`, `France`)

## Тесты

```bash
pytest --cov=src --cov-report=term-missing
```

Тесты не обращаются к интернету: запросы к API подменяются заглушками.

## Структура проекта

```
main.py                    точка входа, сборка компонентов
src/
  base_api.py              BaseAPI — абстрактный класс для работы с API
  api.py                   NominatimAPI, OpenSkyAPI, APIAdapter
  aeroplane.py             Aeroplane — самолёт (инкапсуляция, валидация, сравнение)
  base_storage.py          BaseStorage — абстрактный класс хранилища
  json_storage.py          JSONStorage — хранение в JSON-файле
  user_interface.py        консольное меню и вспомогательные функции
  main.py                  
tests/                     тесты
data/aeroplanes.json       сохранённые данные (создаётся при работе)
```

## Архитектура

- **`BaseAPI`** — единый абстрактный класс для обоих сервисов: общая отправка запроса и обработка ошибок, абстрактный метод `get_data`. `NominatimAPI` возвращает границы страны, `OpenSkyAPI` — самолёты в этих границах.
- **`APIAdapter`** объединяет два API. Зависимости передаются через конструктор, поэтому их легко заменить.
- **`Aeroplane`** хранит данные в закрытых атрибутах; доступ — через свойства с валидацией. Умеет сравнивать самолёты по скорости (`compare_speed`) и высоте (`compare_height`), создаваться из записи OpenSky (`plane_from_opensky`) и из словаря (`from_dict`).
- **`BaseStorage`** задаёт интерфейс хранилища: добавление, получение по критериям, удаление. Методы `connect` и `close` в `JSONStorage` — заглушки, которые понадобятся при подключении базы данных.
- **`JSONStorage`** — реализация хранилища на JSON. Чтобы использовать другое хранилище (CSV, БД), достаточно написать новый наследник `BaseStorage` и передать его в `main.py`.


## Формат данных

Каждый самолёт в `aeroplanes.json` выглядит так:

```json
{
    "icao24": "abc123",
    "callsign": "AFL123",
    "origin_country": "Spain",
    "speed": 230.5,
    "altitude": 10000.0,
    "on_ground": false
}
```

Скорость указана в м/с, высота (барометрическая) — в метрах.

## Ограничения

- Территория страны определяется прямоугольником (`boundingbox`), поэтому в выборку могут попасть самолёты над соседними странами.
- Анонимный доступ к OpenSky ограничен по частоте запросов; при превышении лимита (ошибка 429) программа сообщит об ошибке, и запрос нужно повторить позже.
- Если OpenSky не передал скорость или высоту, в данных сохраняется `0.0`.
